## This is a post to show you my RGB Loop assignment, but now on my Arduino!

This was the first assignment where we got to use our Arduino. So, we took the code in C from last time, and updated it. Last time, we had to make a loop that would print out RED three times, then GREEN three times, then BLUE three times, only on the 10th run through of the loop. This time, we had to make a loop that would flash on a red LED three times, then a green LED three times, then a blue LED three times, still only on the 10th run through of the loop.
